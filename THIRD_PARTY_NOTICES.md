# Third party notices

Knowledge Hub's own licensing is described in [LICENSE.md](LICENSE.md). This file
covers material from other people.

The distinction that matters here is what reaches a reader. Knowledge Hub is a
static site, so most of its dependencies are build tools that never leave this
machine. Only a small set of files is actually served.

## What is served to a reader

Three variable fonts, self hosted rather than loaded from a font service, so no
reader request goes to a third party.

| Font | Used for | License | Copyright |
| --- | --- | --- | --- |
| [Lora](https://github.com/cyrealtype/Lora-Cyrillic) | Display and headings | OFL-1.1 | Copyright 2011 The Lora Project Authors, with Reserved Font Name "Lora" |
| [Work Sans](https://github.com/weiweihuanghuang/Work-Sans) | Body and interface | OFL-1.1 | Copyright 2019 The Work Sans Project Authors |
| [Roboto Mono](https://github.com/googlefonts/robotomono) | Code | OFL-1.1 | Copyright 2015 The Roboto Mono Project Authors |

They are packaged by [Fontsource](https://fontsource.org/) and subsetted to the
Latin range. The SIL Open Font License, Version 1.1 is reproduced in
[`LICENSES/OFL-1.1.txt`](LICENSES/OFL-1.1.txt).

Everything else served is generated by this repository: HTML, CSS, SVG, and one
small client script. No third party JavaScript is shipped, and no analytics,
tracking, or content delivery network is used.

of them ship. The distribution is:

Two entries deserve to be called out rather than buried in a count, because they
are the only ones with reciprocal terms:

- **`lightningcss` and `lightningcss-darwin-arm64`** (MPL-2.0). A CSS transformer
  used by the build. Its own source stays under MPL-2.0; it is not modified here
  and its code is not included in the output.
- **`@img/sharp-libvips-darwin-arm64`** (LGPL-3.0-or-later). A native image
  library pulled in transitively by the build toolchain. It is a build time
  binary, is not linked into anything published, and no part of it is served.

Neither affects the license of this repository's own output, because neither is
distributed with it.

The authoritative, exact list of every dependency and version is
[`pnpm-lock.yaml`](pnpm-lock.yaml). To regenerate this inventory:

```bash
pnpm licenses list --prod
```

## Sources cited in lessons

Lessons cite primary sources in their Evidence Record. Those citations are
references, not redistribution: no third party text is copied into a lesson, and
each source keeps its own copyright. See a lesson's `evidence` block in
`lessons/**/lesson.yaml` for what a given lesson relies on.

reporting. Please open an issue.
